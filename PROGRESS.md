# DevGraph Implementation Progress

## Week 1 — Foundations, Ingestion, Environment
- **What was built:** Repo layout, `docker-compose.yml` (Neo4j Community 5.26), `devgraph/config.py`, typed Pydantic data models (`devgraph/models.py`), full-history Git cloner with SHA pinning (`devgraph/ingestion/clone.py`), paginated & cached GitHub metadata ingestion (`devgraph/ingestion/github_meta.py`), `scripts/repos.yaml`, `scripts/index_repo.py`, and `tests/test_ingestion.py`.
- **What broke & fixes:** Docker daemon initially required systemd socket activation (`systemctl start docker.socket`); `data/` directory created by Docker container defaulted to `nobody` ownership, resolved by chowning to local user (`1000:1000`) and enforcing proper folder permissions.
- **Numbers obtained:** Pilot repo `pallets/click` cloned with full history; HEAD SHA pinned at `2247b35ea1c47c727d7a06e51fa280e12a863ff6`; cached 10 issues and 10 PRs (configurable up to 300); Neo4j read/write verified; all 5 tests in `tests/test_ingestion.py` passed (100%).
- **Next phase:** Week 2 — Structural extraction (Tree-sitter AST, files, classes, functions, imports, calls) and building the first graph in Neo4j.
- **Notes & Viva defense:** Head commit SHA is pinned to ensure full evaluation reproducibility and enforce strict temporal isolation (preventing future information leakage).

## Week 2 — Structural Extraction → First Graph in Neo4j
- **What was built:** `devgraph/extraction/resolver.py` (`src/` and relative import resolver, third-party filter), `devgraph/extraction/structural.py` (Tree-sitter AST queries, class/function interval nesting, import & call extraction, derived `DEPENDS_ON`), `devgraph/graph/neo4j_store.py` (schema constraints, batched `UNWIND MERGE` writers for nodes and edges with provenance), `tests/test_structural.py` (3 synthetic fixture tests + Neo4j integration test), and updated `scripts/index_repo.py` supporting `--stage structural`.
- **What broke & fixes:** (1) Neo4j unique constraint creation on host initially failed due to Docker volume directory permissions (`schema/index/range-1.0` owned by `neo4j` UID 7474), resolved by fixing volume permissions. (2) Tree-sitter C extension `node.text` and `node.start_point` produced memory alignment / pointer faults on deep expression trees under Python 3.13; resolved by pre-compiling Tree-sitter Queries (`QueryCursor`), slicing text directly from Python source byte offsets `content[node.start_byte:node.end_byte]`, and computing lines via newline counting.
- **Numbers obtained:** Pilot repo `pallets/click` (91 Python files) extracted in 1.23s: 91 Files, 181 Classes, 1,897 Functions, 2,078 CONTAINS, 2,078 DEFINES, 165 IMPORTS, 436 CALLS, and 165 DEPENDS_ON edges. Resolved 333 of 333 internal candidate imports (**100.00% resolved import rate**, exceeding DoD threshold ≥ 80%). Neo4j graph verified with 2,170 nodes and 5,013 edges. All 8 tests in `pytest tests/` passed (100%).
- **Next phase:** Week 3 — Evolution Miner (PyDriller commit walk, SQLite Evolution DB, noise filters, co-change decay queries, and issue link extraction).
- **Notes & Viva defense:** `CALLS` edges are marked deterministic with a footnote because AST extraction of call sites is factual, while resolving dynamic Python symbol names across scopes is best-effort approximation.
